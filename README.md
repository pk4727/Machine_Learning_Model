# MACHINE_LEARNING_MODEL

A collection of diverse machine learning and data science projects covering image processing, disease prediction, sentiment analysis, sales forecasting, and more. This repository serves as a comprehensive workspace for experimentation, research, and practical applications of ML models.

## 📂 Project Structure

### 1. **Here you will find Two Folder**

1. `Main` folder -> All machine learning model
2. `Public_app_of_ML_by_streamlit` folder -> used in streamlit for creating public url

### 2. **Datasets**

Contains raw and processed datasets used across different projects.

### 3. **Dehazing-model**

Projects focused on image and video dehazing:

- Image dehazing
- Video dehazing
- Live video dehazing

### 4. **Internship_coding_raja**

- `IMAGE_CLASSIFICATION_FOR_FOOD_RECOGNITION.ipynb` – Food image classification using deep learning.
- `SENTIMENT_ANALYSIS_ON_SOCIAL_MEDIA.ipynb` – Sentiment analysis on social media text.

### 5. **Log Analysis**

- `Log Analysis Assignment.py` – Python script for log file analysis.
- `log_analysis_results.csv` – Output results.
- `sample data.log` – Example log file.
- `README.md` – Documentation for log analysis.

### 6. **multiple_diseases_prediction_code**

Machine learning models for disease prediction:

- Breast Cancer Prediction (ML & Neural Networks)
- Diabetes Prediction
- Heart Disease Prediction
- Parkinson’s Disease Prediction

### 7. **Others**

Miscellaneous ML projects:

- `big_mart_sales_prediction.ipynb` – Sales forecasting.
- `Bostan_house_prediction.ipynb` – Housing price prediction.
- `Calories_Burnt_prediction.ipynb` – Fitness-related prediction.
- `customer_segmentation_using_K-means.ipynb` – Clustering customers.
- `loan-prediction.ipynb` – Loan approval prediction.
- `rock_and_mine.ipynb` – Rock vs Mine classification.
- `spam_mail_checking.ipynb` – Spam detection.
